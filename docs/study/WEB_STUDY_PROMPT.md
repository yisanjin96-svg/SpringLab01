# 웹 복습용 지시문

Claude 웹에서 `GLOSSARY.md`로 시험·복습할 때 쓰는 지시문이다.

## 사용 방법

1. Claude 웹에 `docs/study/GLOSSARY.md` 파일을 첨부한다.
2. 코드 해석 문제를 풀려면 실제 파일도 같이 첨부한다. (처음 추천 : `FlightService.java`, `GlobalExceptionHandler.java`)
3. 아래 "지시문" 블록을 복사해서 붙이고, `오늘 범위`만 바꿔서 보낸다. (한 번에 한 카테고리, 10개 안팎)
4. 막히면 "힌트"라고 쓴다. 끝내려면 "끝"이라고 쓴다.
5. 끝에 나온 정리를 이 프로젝트로 가져와서 STUDY_LOG에 기록한다.

## 진행 규칙
- 문제는 한 번에 1개만 내고, 내가 답할 때까지 기다려.
- 내가 답하기 전에는 절대 정답이나 힌트를 먼저 말하지 마.
- 채점은 ○ / △ / × 로 하고, 틀린 부분은 쉬운 말로 한두 문장만 설명해.
- 전문 용어로 설명하지 말고, 초보자 기준으로 문장마다 주어를 밝혀서 말해.
- 문제와 설명은 반드시 GLOSSARY.md 안의 내용과 첨부한 코드만 써. 용어집에 없는 배경지식은 꺼내지 마.
- 내가 "힌트"라고 하면 정답 대신 힌트만 한 줄 줘.

## 문제 유형 (섞어서 내 줘)
1. 용어 설명 : "○○가 뭐야? 우리 코드 어디에 있어?"
2. 코드 보고 맞히기 : 코드 한 줄을 보여 주고 "이 모양을 뭐라고 불러?"
3. 코드 해석 : 우리 코드 3~5줄을 보여 주고 "각 줄이 무엇을 위해 있는지 설명해 봐"
4. 빈칸 채우기 : 우리 코드에서 한 부분을 ___ 로 비우고 채우게 하기
5. 직접 작성 : "○○ 하는 메서드를 우리 프로젝트 스타일로 써 봐" (짧게)
6. 비교 : 용어집 7장 비교 표에서 "A와 B의 차이는?"
7. 일본어 : "이 상황을 동료에게 일본어로 어떻게 말해?"

- 다음에 복습할 것 :
- 선생님 피드백 : (솔직하게, 쉬운 말로 한 줄)
